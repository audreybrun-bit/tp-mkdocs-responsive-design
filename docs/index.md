# Accueil

Bienvenue sur ce site réalisé dans le cadre de notre Master en Ingénierie Pédagogique Multimodale (IPM) avec l'Université de Lille.

Produit en Markdown avec MkDocs Material, ce site présente trois outils web essentiels pour faire du responsive design :

- les média queries
- Bootstrap
- MkDocs

Il présente leur intérêt et leur mobilisation dans une démarche d'ingénierie pédagogique numérique.

![image accueil](img/accueil.png)
*Image générée par IA*

Ce site est propulsé par MkDocs Material et hébergé sur GitLab Pages. Son fonctionnement illustre un principe simple mais puissant pour la production de ressources pédagogiques : écrire du contenu en Markdown, laisser MkDocs le transformer en pages HTML, puis publier automatiquement via GitLab Pages.

## Contenus du site

- **Média queries** : comment adapter l'affichage d'un site selon la taille de l'écran.
- **Bootstrap** : un outil pour créer plus rapidement des sites qui s'adaptent à tous les écrans.
- **MkDocs** : l'outil utilisé pour créer ce site lui-même.
- **Analyse réflexive** : en quoi ces outils sont utiles pour le métier d'ingénieur pédagogique (fiche [F2D57](https://data.enseignementsup-recherche.gouv.fr/pages/fiche_emploi_type_referens_iii_itrf/?refine.referens_id=F2D57#top)).
