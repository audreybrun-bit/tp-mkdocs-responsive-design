# Accueil

Bienvenue sur ce mini site réalisé dans le cadre du Master Ingénierie Pédagogique et Multimédia (IPM) à l'Université de Lille.

Produit en Markdown avec MkDocs Material, ce site présente trois outils web incontournables pour le responsive design :

- les média queries
- Bootstrap
- MkDocs

Il interroge leur intérêt et leur mobilisation dans une démarche d'ingénierie pédagogique numérique.

![image accueil](img/accueil.png)

Ce site est propulsé par MkDocs Material et hébergé sur GitLab Pages. Son fonctionnement illustre un principe simple mais puissant pour la production de ressources pédagogiques : écrire du contenu en Markdown, laisser MkDocs le transformer en pages HTML, puis publier automatiquement via GitLab Pages.

## Contenus du site

- **Média queries** : le mécanisme CSS qui adapte l'affichage selon l'écran.
- **Bootstrap** : le framework qui accélère la création d'interfaces responsives.
- **MkDocs** : le générateur de site statique utilisé pour produire ce site.
- **Analyse réflexive** : positionnement de ces outils dans l'activité de l'ingénieur pédagogique (fiche [F2D57](https://data.enseignementsup-recherche.gouv.fr/pages/fiche_emploi_type_referens_iii_itrf/?refine.referens_id=F2D57#top)).
